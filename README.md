# Estudio PJ Mendoza 2026

App web de estudio para el examen de **Conocimientos Específicos** del Concurso de Ingreso Administrativo 2026 del Poder Judicial de Mendoza.

- Resúmenes, mapas conceptuales, tarjetas (flashcards) y tests de los 5 módulos oficiales.
- Simulacro cronometrado: 50 preguntas, 4 opciones, 40 minutos, sin volver atrás.
- Repaso de errores. El progreso se guarda en el navegador.

Sitio estático (HTML + JS sin dependencias). Para correrlo localmente servir la carpeta con cualquier servidor estático, por ejemplo `npx http-server`.

Material basado en el contenido publicado por la Suprema Corte de Justicia de Mendoza. App no oficial.
